# INF04-WP81-W81

Własne implementacje aplikacji z egzaminów zawodowych INF.04 na Windows Phone 8.1 lub Windows 8.1.
Wykonywane w celach hobbystycznych, nie są powiązane z CKE.

Aplikacje mają na celu działanie zgodne z arkuszem, natomiast wygląd to własna interpretacja. Sugeruję się treścią zadania oraz chcę jak najbardziej uddać styl Windowsa 8.x. Jakby to była dedykowana aplikacja napisana dla tej rodziny systemów.
Używane grafiki są tworzone przeze mnie.

Pliki mojej implementacji aplikacji z egzaminu zawodowego są w folderach <System>/<Nazwa aplikacji - nazwa arkusza>/<Aplikacja.zip + pliki instalacyjne>

Nie jestem profesjonalnym programistą, wciąż się uczę i tak wiem, istnieją inne, lepsze rozwiązania, ale ja piszę po swojemu, na tyle na ile jestem w stanie
